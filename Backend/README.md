1. In the Supabase SQL editor run: sql/enums.sql, then sql/missing_tables.sql
2. Copy .env.example to .env and fill DATABASE_URL and JWT_SECRET
3. npm install
4. npm start, then open http://localhost:3000
5. Register your account, then run sql/admin.sql (with your email) to become System Admin, and log in again.
Modules: 1 Auth, 2 Profile, 3 Trips, 4 Discover, 5 Like/Skip + match, 6 Chat + Groups + Alerts, 7 Safety + Admin.
